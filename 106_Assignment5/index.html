⚙️ Assignment 5: RESTful APIs

Node.js & Express API Development with MongoDB & In-Memory Data Storage

📦 Part A: MongoDB + Mongoose CRUD API

Full CRUD REST API connected to a local MongoDB database (studentDB) managing student records with Schema validation (name, city, marks).

# How to run locally: cd "106_Assignment5/Part A" npm install node array.js # Runs on http://localhost:3000

API Endpoints

GET /students
Retrieves all student documents from MongoDB.
POST /students
Creates and persists a new student in MongoDB.
Body: { "name": "Shraddha", "city": "Pune", "marks": 95 }
PUT /students/:id
Updates an existing student by MongoDB Object _id.
Body: { "name": "Shraddha", "city": "Mumbai", "marks": 98 }
DELETE /students/:id
Deletes the student matching the specified MongoDB _id.

⚡ Part B: In-Memory Array CRUD API

Lightweight Express REST API performing CRUD operations directly on an in-memory JavaScript array of students.

# How to run locally: cd "106_Assignment5/Part B" npm install node server.js # Runs on http://localhost:3000

API Endpoints

GET /students
Retrieves all students currently stored in the in-memory array.
POST /students
Pushes a new student JSON object to the array.
Body: { "name": "John Doe", "roll": 101 }
PUT /students/:index
Replaces the student element at the specified zero-based array index.
DELETE /students/:index
Removes the student element at the specified array index via splice().
